# Clinic Pro – WhatsApp Appointment Management System

## Overview
Clinic Pro is a web-based clinic appointment management system designed to simplify appointment booking and clinic operations through an integrated frontend, backend and WhatsApp-based communication workflow.

## Features
- Appointment booking and management
- Frontend and backend architecture
- Booking validation
- WhatsApp bot integration
- Appointment status and scheduling workflows

## Project Structure
- `backend/` – Backend application
- `frontend/` – Frontend application

## Technologies
- Python
- JavaScript
- WhatsApp integration

## Getting Started
Clone the repository:

```bash
git clone https://github.com/jessicanalinipaully/clinic-pro-whatsapp.git
```

Open the project folder and follow the setup instructions for the frontend and backend.
